# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Email **temidireadesiji@gmail.com** with:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

You will receive an acknowledgement within 48 hours and a resolution timeline within 5 business days.

All reports are handled confidentially. Credit will be given in the changelog unless you prefer to remain anonymous.
